# Virtual HR Dashboard

## Overview
This is a mini ATS system where:
- Employer assigns tasks
- Virtual HR updates tasks
- Interview scheduling is supported
- Tasks are monitored in real-time

## Tech Stack
- FastAPI (Backend)
- React (Frontend)
- SQLite (Database)

## Features
- Task assignment
- Task tracking
- Role-based UI
- Interview scheduling (Video/Voice/Chat)
- Auto-refresh dashboard

## Setup Instructions

### Backend
cd Backend
uvicorn main:app --reload

### Frontend
cd frontend
npm install
npm start
